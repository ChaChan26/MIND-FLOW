## 2. Key Architectural Deliverables

### A. Windows System Tray & Zero-Dependency Daemon Mode
- **Module**: `native/src/MindFlow.Win32/Tray/TrayIconManager.cs`
- **Design Decisions**:
  - Implemented direct P/Invoke bindings to `Shell32.dll` (`Shell_NotifyIconW`) and `User32.dll` (`CreateIconIndirect`, `DestroyIcon`) rather than introducing `System.Windows.Forms` or 3rd-party dependencies.
  - Subclassed the WPF main window procedure (`HwndSourceHook`) to intercept custom notification messages (`WM_APP + 100`).
  - Supports left-click window show/restore, right-click dark-themed context menu (`Open`, `Pause Tracking`, `Reset Battery`, `Exit`), and standard Windows balloon notifications.
- **Autostart Governance**:
  - `native/src/MindFlow.Win32/Power/AutostartManager.cs` safely manipulates `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` with the `--background` argument for silent startup at logon.
- **Minimize-to-Tray Invariant**:
  - Closing the desktop window (`OnClosing`) cancels the termination event and hides the window into the background notification tray, preserving tracking continuity.

### B. Focus Sprint & Rest Recovery Engine
- **Module**: `native/src/MindFlow.Core/Focus/FocusTimerEngine.cs`
- **Interval Presets**:
  - Pomodoro Sprint (25m work / 5m break)
  - Deep Flow Sprint (50m work / 10m break)
  - Ultradian Rhythm (90m work / 20m break)
- **Features**:
  - Progress calculation (`0.0` to `1.0`), remaining seconds tracking, and formatted countdown string (`MM:SS`).
  - Safe pause/resume semantics that do not advance timers during interruptions.
  - Completion event notifications (`SessionCompleted`) triggering custom system chimes and battery recovery bonuses.

### C. Context Switch Telemetry & Friction Metrics
- **Module**: `native/src/MindFlow.Core/Telemetry/ContextSwitchTracker.cs`
- **Mathematical Modeling**:
  - Maintains a rolling 15-minute sliding window of process transitions.
  - Filters consecutive duplicate process activations to prevent spurious switch counts.
  - Computes switching velocity (`SwitchesPerMinute = SwitchesLast15Min / 15.0`).
  - Classifies mental friction into 3 tiers:
    - **Low (< 0.5/min)**: Deep Focus state, minimal task-switching overhead.
    - **Moderate (0.5 - 1.5/min)**: Active Multitasking, standard cognitive load.
    - **High (> 1.5/min)**: Fragmented Focus, triggers severe stamina battery drain penalties.
- **Battery Engine Integration**:
  - Wired real-time `SwitchesPerMinute` directly into `CognitiveBattery.ProcessTick(..., contextSwitchesPerMin: rate)`, activating the dynamic fatigue multiplier:
    $$\text{penalty} = (1.0 + \text{work} \times 0.035) \times (1.0 + 0.15 \times \text{switchesPerMin})$$

### D. Multi-Screen WPF MVVM Presentation Layer
- **Modules**: `native/src/MindFlow.Desktop/MainWindow.xaml`, `MainWindow.xaml.cs`, `ViewModels/MainViewModel.cs`, `Styles/Theme.xaml`
- **Dynamic View Engine**:
  - Engineered zero-allocation view switching using pure XAML `DataTrigger` styles keyed to `CurrentScreen` (`"Dashboard"`, `"Zen"`, `"Analytics"`, `"Preferences"`).
  - **Focus HUD**: Real-time Cognitive Battery stamina bar, Focus Sprint countdown card with start/pause/reset controls, Active Window telemetry, and Context Switch Friction badge.
  - **Zen Sanctuary**: 4-7-8 rhythmic breathing circle with smooth double-animation scale keyframes, soothing ambient instructions, and instant battery recharge boost.
  - **Analytics View**: Hourly productivity breakdown data grid (Work vs. Recharge vs. Flow minutes) and process switching velocity gauges.
  - **Preferences View**: Runtime engine telemetry, auto-start toggle, and legal copyright attribution ledger.

### E. Time-Series Persistence & Asynchronous Flush Semantics
- **Module**: `native/src/MindFlow.Data/Database/MindFlowDb.cs`
- **Channel Write Queue**:
  - Unbounded concurrent write requests are piped into a `System.Threading.Channels.Channel<Func<SqliteConnection, Task>>` bounded at 1,000 operations, processed by a dedicated worker task.
  - Added `FlushAsync()` using a `TaskCompletionSource<bool>` barrier pattern to guarantee deterministic SQLite commit sequencing before reads or during shutdown.
  - Added `LogContextSwitchAsync`, `GetTodayContextSwitchCountAsync`, and `GetTodayHourlyProductivityAsync` (aggregating work, recharge, and flow minutes grouped by hour).
