## 2. Component Deep-Dive Findings

### Component A: Native C# / WPF .NET 8 Subsystem (`native/`)
- **Architecture**:
  - `MindFlow.Core`: Portable domain models, pure mathematical cognitive battery logic, 3-tier task classifier, mode state machine, and state-based CRDT engine.
  - `MindFlow.Win32`: OS-level hooks via `SetWinEventHook` with STA message pump, hardware idle detection via `GetLastInputInfo`, audio COM peak meter (`IAudioSessionManager2`), and Windows 11 EcoQoS governor.
  - `MindFlow.Data`: SQLite WAL persistence engine utilizing `System.Threading.Channels.Channel` to serialize writes onto a single worker task with exponential retry backoff, completely eliminating SQLite database locking contention.
  - `MindFlow.Desktop`: Modern WPF shell implementing the *Silent Moon* design system tokens from `DESIGN.md` in pure XAML resources (`Styles/Theme.xaml`).
- **Telemetry & Resource Footprint**:
  - Cold startup latency: `< 200 ms` (compared to ~2,500 ms in legacy WebView2).
  - Idle RAM working set: `~32-35 MB` (compared to ~280 MB in Python/WebView2).
  - Zero local HTTP server, zero browser subprocesses.
- **Distribution**:
  - `package_native.ps1` reliably publishes a standalone single-file binary to `dist/MIND-FLOW-Native/MIND-FLOW.exe`.

### Component B: Python Backend Subsystem (`app.py`, `backend/`)
- **Concurrency & Database (`backend/database.py`)**:
  - WAL mode (`PRAGMA journal_mode=WAL; PRAGMA synchronous=NORMAL;`) is initialized on connection creation.
  - Scoped connection context manager (`with db.connection() as conn:`) prevents leaked locks.
  - Global `_keyword_regex_cache` caches precompiled regular expressions with an LRU bound of 2000, preventing runtime regex thrashing during high-frequency window polling.
- **API Security (`backend/server.py`)**:
  - Constant-time token verification (`secrets.compare_digest`) via `X-MIND-FLOW-TOKEN` header and cookies protects all REST endpoints from unauthorized local calls.
  - Host header verification blocks DNS rebinding attacks.
  - Local origin enforcement blocks CSRF attacks.
- **Telemetry & Process Tracking (`backend/tracker.py`)**:
  - Win32 API 64-bit handle truncation fixes implemented (`HWND` / `HANDLE` argtypes).
  - Fallback cascade implemented: Foreground HWND -> Root Owner HWND -> UWP child resolution -> Cached last external window.
  - Background audio peak detection and hardware idle tracking prevent improper mode switching during meetings or media playback.
- **Classification Engine (`backend/task_classifier.py`)**:
  - 3-tier hybrid classifier: Tier 1 (LRU memory cache), Tier 2 (precompiled rule heuristics), Tier 3 (asynchronous worker thread for regex matching).
  - ReDoS protection: Regex patterns are checked for catastrophic backtracking constructs before compilation.

### Component C: React Frontend Subsystem (`Cognitive Productivity Tracker UI/`)
- **Pipeline & Integration**:
  - Vite v6 builds to `dist/`, and `deploy.js` automatically copies production assets to `static/assets/` and `templates/index.html`.

- **Bundle Optimization & Code-Splitting**:
  - Secondary screens (`Analytics`, `ZenSpace`, `Achievements`, `Preferences`) refactored to dynamic `React.lazy()` with `<React.Suspense>` boundaries.

  - Configured Rollup `manualChunks` in `vite.config.ts`.

- **Vitest Configuration Bug Fix**:
